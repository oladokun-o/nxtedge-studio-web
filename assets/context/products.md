# Nxtedge Products

## Nxtflo
Nxtflo is an AI-powered agency operating system built by Nxtedge Studio.

Long-term goal: productize Nxtflo as SaaS for freelancers, studios and agencies.

Core journey:
client onboarding → structured brief → proposal → e-signature → project delivery.

Current direction:
- Shareable client intake
- Step-by-step questionnaire
- Branching logic
- Progress saving / resume
- AI-generated structured project brief
- Proposal generation
- Client e-signature
- Shareable proposal
- WhatsApp/email communication
- Future project delivery/reporting

Technical context:
- SvelteKit
- Node.js
- MongoDB Atlas
- Vercel
- Claude API for AI brief generation
- Stitch for UI/design workflows

Phases:
- Phase 1: Client onboarding/questionnaire — complete
- Phase 2: AI structuring engine / Claude API brief generation — next/in progress
- Phase 3: Proposal generation, e-signature and PDF — defined
- Phase 4: Project delivery/reporting — not yet detailed

Principles:
- Step-by-step UX rather than long single-page forms
- Progress saving matters
- WhatsApp and email are both important channels
- Real Nxtedge client work is used as a stress test
- Validate before expanding

Working pricing hypothesis:
- Free: ₦0
- Solo: ₦5k/month or ₦50k/year
- Studio: ₦15k/month or ₦150k/year
- Agency: ₦35k/month or ₦350k/year
International reference pricing considered: approximately $9/$29/$79. Pricing remains subject to validation.

## Nxtpay
Nxtpay is Nxtedge's payroll product opportunity.

Working commercial model:
- ₦500,000 one-time implementation
- ₦900 per employee/month

Initial MVP:
- Employee records
- Payroll inputs and calculations
- Payroll rules
- Payroll runs and approval
- Payslips and reports
- Secure access and auditability
- Customer account/subscription management
- Multi-tenant, reusable architecture

The first customer should function as a design partner. The next customer should be configurable without requiring a bespoke rebuild.

Go/no-go criteria:
- Customer pays implementation
- Subscription economics are sustainable
- Support burden is manageable
- Implementation is reusable
- Additional customers can be acquired without proportional delivery effort

Nxtpay and Nxtflo are strategic owned products. They should be validated before major expansion or overhead.
