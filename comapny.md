## Broader Vision — Nxtflo Pipeline

Nxtedge Studio is developing **Nxtflo**, an **AI-powered internal agency operating system** that streamlines the full project lifecycle:

### Pipeline Flow
```

Raw idea / conversation → AI-assisted structuring → Scoping & solution design → Costing & proposal → Payment → Build → Delivery

```

### Three System Layers

#### Layer 1 — Intake & Structuring
- Input: voice notes, transcripts, WhatsApp messages, rough briefs
- AI processes input into **structured project scopes**
- Current priority for internal development

#### Layer 2 — Scoping & Proposal
- Converts structured scopes into **cost estimates** and **formal proposals**
- AI-assisted and largely templated
- Proposals sent directly to clients

#### Layer 3 — Delivery & Architecture
- Data from Layer 1 & 2 informs **tech stack, tools, and architecture decisions**
- Tracks project progress through to delivery
- Ensures **consistency and efficiency** across projects

**Tech Stack Direction**
- **AI Backbone:** Claude API
- **Interface:** Web app (SvelteKit + Node.js + MongoDB + Vercel)
- **Design/Assets:** Stitch/Gemini
- Internal use first, then productized as a **SaaS for other agencies**
