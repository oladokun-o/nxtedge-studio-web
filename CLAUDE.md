## Broader Vision — System Architecture

### The Three Layers

**Layer 1 — Intake & Structuring**
- Input: voice notes, transcripts, WhatsApp messages, rough briefs
- AI processes and structures input into a proper project scope
- This is the most immediate priority to build

**Layer 2 — Scoping & Proposal**
- Converts structured scope into cost estimates and proposals
- Largely templated and AI-assisted
- Proposal sent directly to client from the system

**Layer 3 — Delivery & Architecture**
- Data from Layer 1 & 2 informs stack, tools, and architecture decisions
- Tracks project progress through to delivery

### Tech Stack Direction
- AI Backbone: Claude API
- Interface: Web app (accessible to team anywhere)
- Start internal, productize later

### Build Order
1. Start with Layer 1 only — intake and structuring
2. Use Quench Beverages projects as the first real test case
3. Refine through real use, then expand to Layer 2 and 3
4. Eventually expose as a product for other agencies/freelancers
